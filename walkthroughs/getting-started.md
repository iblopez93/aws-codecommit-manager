# Getting Started with AWS CodeCommit

This walkthrough takes you from configuration to your first pull request.

1. **Configure the connection** — set the AWS region and the shared credentials profile.
2. **Log in with SSO** — run the Login command and complete the device authorization in your browser.
3. **Browse** — expand a repository in the AWS CodeCommit view to see branches, files, and commits.
4. **Commit** — upload a file or create an atomic commit from local files.
5. **Pull request** — create a pull request between branches and review the differences with comments.
